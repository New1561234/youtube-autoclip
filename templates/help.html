How Clip Studio works

Everything you need to go from a YouTube link to a share-ready vertical clip.

1 Quick start

Four steps and you are done. The whole pipeline runs locally on your machine.

  1. Paste a YouTube link. Use any standard watch, Shorts, or youtu.be URL. The paste button reads straight from your clipboard.
  2. Pick your clip length. Drag the duration slider anywhere from 10 to 300 seconds. The default is 45 seconds.
  3. Set the lead-in. Context before adds extra seconds ahead of the detected highlight so the moment does not start abruptly.
  4. Hit Generate clip. Follow the live pipeline, then preview and download the finished MP4 from the result card.

2 Supported URL formats

Clip Studio accepts the common YouTube link shapes. Each must contain an 11-character video ID.

https://www.youtube.com/watch?v=VIDEO_ID https://youtu.be/VIDEO_ID https://www.youtube.com/shorts/VIDEO_ID https://www.youtube.com/live/VIDEO_ID https://www.youtube.com/embed/VIDEO_ID https://m.youtube.com/watch?v=VIDEO_ID https://music.youtube.com/watch?v=VIDEO_ID

Playlists and channel URLs are not supported — use a link to a single video. Live-stream VODs work via /live/ links; an actively broadcasting stream is captured from the start, but is limited by the 10-minute download window and has no “most replayed” heatmap (audio-energy fallback is used).

3 Settings reference

Both settings are clamped to safe ranges on the server, so out-of-range values are corrected automatically.

SettingDefaultRangeWhat it does
clip_duration 45 10 – 300 s Target length of the exported vertical clip in seconds.
context_before 10 0 – 60 s Extra seconds added before the detected highlight so the cut has breathing room.

4 Output & privacy

Clips are rendered as 9:16 vertical MP4 files and served straight from the local server for instant preview.

  • Resolution: 9:16 vertical, 1080p-class output.
  • File name: <video_id>_clip.mp4, stored under a per-job folder so nothing is ever overwritten.
  • Audio: included whenever the source video has an audio track.
  • Local only: the server binds to 127.0.0.1. Your links and clips never leave your machine.
  • Heatmap: uses YouTube’s “most replayed” data when available, otherwise falls back to audio-energy analysis.
Respect creators. This tool processes YouTube content. Only clip material you own or have permission to use, and follow YouTube’s Terms of Service.

5 Connecting & uploading to YouTube

Uploading is optional and always requires your explicit approval. It uses Google OAuth 2.0 and the YouTube Data API v3 — not your Gemini API key. You only need to set it up once.

  1. Create a Google Cloud project. Open the Google Cloud Console, create (or pick) a project, and note its name.
  2. Enable the YouTube Data API v3. Go to APIs & Services → Library, search for YouTube Data API v3, and click Enable.
  3. Configure the OAuth consent screen. Under APIs & Services → OAuth consent screen, choose External (or Internal if you use a Google Workspace org), fill in the app name and support email, and add your own Google account as a Test user. Add the two scopes below if you are asked to: youtube.upload and youtube.readonly.
  4. Create an OAuth client ID. Under Credentials → Create credentials → OAuth client ID, choose Web application. Under Authorized redirect URIs add exactly http://127.0.0.1:5000/youtube/oauth2callback. This must match the local server address — if you run on a different port, update the redirect URI here and in youtube_auth.REDIRECT_URI.
  5. Save the client secret. Download the JSON and save it as credentials/client_secret.json in the project folder. This file is git-ignored and must never be shared or committed.
  6. Connect. Restart the server, open Clip Studio, and click Connect YouTube in the top bar. Approve the requested permissions and you will return to the app. Your access token is stored locally in credentials/token.json (also git-ignored). Click the disconnect icon to revoke it at any time.

Uploading a clip

Once a clip is ready, the result card shows an Upload to YouTube panel. You can edit the title, description, and privacy before uploading. Uploads default to Private, and nothing is sent until you tick the confirmation box and press Upload. When it finishes you get a direct link to the video. Each clip can only be uploaded once — repeated clicks are ignored.

About Shorts

YouTube — not this app — decides whether a video is classified as a Short. The API cannot guarantee Shorts classification. The clip stays in vertical 9:16 output, and adding #shorts to the title or description may help YouTube recognise it.

Verification & quotas. Apps in Testing mode have a small pool of test users and refresh tokens expire after ~7 days; click Connect again if uploads stop working. Uploading is subject to the YouTube Data API quota (a video insert costs ~1600 units; the default daily quota is 10,000 units). Unverified apps can only upload private videos until they pass Google’s OAuth verification.
Credentials stay local. Client secrets and access tokens are stored only in the git-ignored credentials/ folder. They are never exposed to the browser, logs, or source control. Only upload clips you own or have permission to publish.

6 Troubleshooting & FAQ

Common issues and how to resolve them.

The job fails with a bot-check or sign-in error
YouTube sometimes blocks automated downloads. Wait a few minutes and retry, or download the video manually and analyse it locally. Age-restricted or members-only videos cannot be fetched.
No heatmap data was found for this video
Heatmap (“most replayed”) data is not available for every video — newer uploads, live VODs, and low-traffic videos often lack it. The pipeline automatically falls back to audio-energy analysis to pick the highlight.
The clip never renders / an ffmpeg error appears
Rendering requires ffmpeg on your PATH. If it is missing, install ffmpeg and restart the server. The job will report a “Render error” with the underlying message.
The selected segment is shorter than 3 seconds
Very short source videos can produce a segment under the 3-second minimum. Try a longer source, a larger clip duration, or more context before.
The download link does nothing
Downloads are served inline from the local server. If the tab is blocked, use “Open in new tab” or right-click the link and choose Save As. Generated files live under the jobs/ folder.
YouTube upload fails or says “not connected”
Make sure credentials/client_secret.json exists, the YouTube Data API v3 is enabled, and you clicked Connect YouTube. If the OAuth app is still in Testing, reconnect about every 7 days because the refresh token expires. Unverified apps can only upload private videos.
Which video formats are accepted as input?
Standard YouTube watch URLs, youtu.be short links, Shorts, embeds, and mobile/music domains are all accepted as long as they contain an 11-character video ID.
